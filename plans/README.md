## Findings considered and rejected

- **pgvector HNSW/IVFFlat index**: re-checked at 31,288 chunks (plan 018). The dense scan is ~140 ms while the cross-encoder is ~2180 ms, so an ANN index would trim a small slice and leave p95 rerank-bound. Sequential `ORDER BY embedding <=>` stays; rerank cost is the target (plan 023). Revisit only if a future bench shows the scan dominating.
- **Fine-tune embedder/reranker on the freeze**: forbidden by `DECISIONS.md` (“Why not fine-tune”).
- **Second chat or embed vendor**: forbidden; Groq is generation-only; nomic ONNX is the same open weights, not a second billed embed provider.
- **Chat-as-homepage / connector marketplace**: out of product scope (`DECISIONS.md` C4/C8/C9).
- **Row-by-row `insert_chunks`**: 14 docs × ~10 chunks; ingest is snapshot-bound, not insert-bound.
- **Uvicorn `--workers` > 1**: each worker would load nomic ONNX (~0.5 GB) plus FlashRank; RAM cost dominates any concurrency win for a single-user bench. Measure first; not a first patch.
- **LangGraph compile-once**: `generate()` closes over a per-request `stage_sink`, so a naive module-level `compile()` is incorrect. Compile cost is tiny vs Groq chat. Do not rewrite the graph in these plans. (Reported again by the performance pass; still rejected.)
- **Web `recharts` code-split**: Traces/Evals charts are the demo screenshot surface, not a rarely-hit route.
- **Pagination on `/traces`**: local JSON glob is fine until traces number in the thousands; revisit if a public demo retains unbounded history.
- **Always-re-fetch ingest skip-by-sha256**: freeze is 14 URLs; correctness of wipe/re-index matters more than skipping HTTP. Do after CORRECTNESS-01 (failure must not delete last-good chunks), not as part of 001–004.
- **Multi-stage API image / bake ONNX into the image**: Compose volumes are the intended cache; image bake is a later deploy concern.
- **Public Playground / no login wall / documented Caddy demo password**: C8 by design.
- **Dark-mode toggle / `next-themes`**: `.dark` tokens exist unused; a toggle is a generic SaaS default. Plan 005 retokens light (paper/ink) only.
- **Chat homepage, suggested-prompt carousel as the `/` focal point, streaming chat UI**: forbidden by `DECISIONS.md`.
- **Marketing analytics product**: still out of scope. The in-app `/metrics` Scoreboard is the C7 scrape rendered for reviewers (null stays unmeasured).
- **Request-body SSRF**: freeze ingest URLs still come from `corpus/MANIFEST.md`. User sources (`POST /corpus/sources`) are HTTPS-only and reject non-public resolved addresses; they are not the eval freeze.
- **SQL injection on retrieve/ingest**: parameterized `%s`; embedding literals are floats.
